	　　我以前用的是mysql-3.23.52-win.zip。安装非常方便好用，结束后现出小绿灯，点击后能直接管理数据库的增加和删除等，这是最方便的。如果你的数据库程序不需要特别的高版本支持，就用这个，最方便，具体可参考我的另一文章。<br /> <br /> 　　现在很多php+mysql的程序只支持4.0以上高版本的mysql了。这时你不如到华军软件园直接下载。注意运行的环境。参考：<a href="https://cyoy.cn/html/19.html" target="_blank" title="https://cyoy.cn/html/19.html">https://cyoy.cn/html/19.html</a><br /> <br /> 　　经实际使用，其中有几点到注意：<br /> <br /> 　　１、在控制面板中停止mysql服务后，再删除老版本，最好也删除以前安装目录文件。注册表改不改好象无所谓。<br /> <br /> 　　２、安装高版本Mysql时，可以一路默认。直到Skip Sign-Up （跳过注册）。配置时，选择　Server Machine -> 选上Online Transaction Processing(OLTP)然后点击Next>继续! 　->　选择语言的支持！默认为Standard Character Set时，应该点&ldquo;Manual sel&#101;cted Defalut Charater Set/Collation&rdquo;选择 utf8 原来的文章介绍是错误的。--> 记得要选上Include Bin Directory In Windows Path 选项.　最后填写密码就ＯＫ了。如果在&ldquo;processing configuration&rdquo;不能正常启动，产行error:0等错误的话，可以删除已经安装的高版本软件后，再重复试一次。<br /> <br /> 　　３、一定要安装　MySQL Control Center 来配置和管理Mysql 数据库！3.23.52倒能管理数据库，高版本反而不行，你只能通过这个来管理。一定要建立一个root%的用户。
