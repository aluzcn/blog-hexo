PowerShell 提示找不到路径：**`kiang.ezimage-1.0.5` 这个文件夹名字不对！**
版本号不一定是 1.0.5，也有可能插件 ID 不是`kiang.ezimage`，我们直接打开文件夹看真实名字。

## 方法 1：资源管理器直接打开，复制真实文件夹名

1. 打开 Windows 资源管理器，顶部地址栏粘贴：

```
C:\Users\cyj9\.vscode\extensions
```

> 
> 你的用户名是`cyj9`，地址刚好匹配报错信息`C:\Users\cyj9\`

2. 回车进入，你会看到所有插件文件夹，**找名字以 `kiang.ezimage` 开头的文件夹**

> 
> 例如：`kiang.ezimage-1.0.2` 或者别的版本号。
> ✅ 把完整文件夹名称**全选复制**

## 方法 2：VSCode 一键打开插件目录（推荐）

1. 打开 VSCode
2. 快捷键 `Ctrl+Shift+P`，弹出命令面板
3. 输入：`Developer: Open Extensions Folder`，点一下

> 
> 自动弹出 extensions 文件夹窗口，直接看到`kiang.ezimage-xxx`文件夹

## ✅拿到真实文件夹名字之后

举个例子：如果你看到文件夹叫`kiang.ezimage-1.0.2`
那 cd 命令就改成：

```
cd "$env:USERPROFILE\.vscode\extensions\kiang.ezimage-1.0.2"
```

粘贴进 PowerShell 回车，再执行 npm 安装命令。

## 📌 排查额外情况

1. 如果文件夹里**根本没有 kiang.ezimage 开头的文件夹**：说明 VSCode 里你**没有安装 EzImage 插件**，要先在 VSCode 插件市场安装 EzImage。
2. 确认：**关闭 VSCode**，再执行 cd 和 npm 命令。

# ✅ 找到了！文件夹名字是 `kiang.ezimage-1.0.3`

现在复制下面这整条 cd 命令，粘贴到 PowerShell 里回车：

```
cd "$env:USERPROFILE\.vscode\extensions\kiang.ezimage-1.0.3"
```

### 操作步骤

1. 先**完全关闭 VSCode**（非常重要，不然文件占用，npm 安装失败）
2. PowerShell（现在是`PS D:\>`）粘贴上面 cd 命令，回车
3. 输入 `pwd` 回车，确认输出路径末尾是 `kiang.ezimage-1.0.3`，代表目录切换成功
4. 再粘贴安装 sharp 的命令，回车执行：

```

npm install sharp --no-save --no-audit --no-fund
```

### 预期结果

命令跑完没有红色报错，就代表 sharp 安装成功。
重新打开 VSCode，EzImage 插件就可以使用图片压缩、转 WebP 功能了。

> 
> 如果提示 'npm' 不是内部命令：说明电脑还没有安装 Node.js，需要先下载安装 Node.js。
