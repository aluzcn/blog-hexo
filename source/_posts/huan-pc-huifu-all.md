## 一、核心真理（记住这一句就够）

\*\*所有博客配置、文章、链接规则、个性化设置，全部都在 `blog-hexo` 文件夹里。
重装系统只会删除电脑环境，不会删除博客配置。\*\*

## 二、重装系统前必做（唯一备份动作）

**完整复制【整个 blog\-hexo 文件夹】备份到网盘 / 移动硬盘**
禁止只备份 posts！必须完整文件夹。

备份包含：

- 全部 1400 \+ 文章

- 固定时间链接规则（不会变链接）

- 404 配置、robots 禁止爬虫配置

- 主题所有样式、设置

- 图片目录、全部源码配置

## 三、重装系统后恢复步骤（固定流程，永远不变）

1. 安装 **Node\.js LTS 版本**（一路默认安装即可）

2. 将备份的 `blog-hexo` 完整文件夹放回电脑（D 盘任意位置）

3. 进入文件夹，打开 PowerShell，执行：

```powershell
npm install
```

自动恢复所有插件、依赖、Hexo 环境。

4. 正常使用命令

```powershell
hexo clean
hexo g
hexo s
```

**所有链接、样式、设置、文章和原来一模一样，零重配。**

## 四、本人固定永久 URL 规则（无需记忆，文件自带）

- 链接格式：`/posts/年/月/日/时/分/秒/`

- URL **只读取文章发布时间，不读取文件名、中文、特殊符号**

- 修改文章正文 **永远不会改变链接**

- 只要不动 md 内 `date:` 字段，链接终身固定

## 五、本人固定永久配置（文件已固化）

1. 禁止搜索引擎收录（robots\.txt 自带）

2. EdgeOne 404 页面生效（edgeone\.json 自带）

3. 更新时间读取规则：date 模式（不改链接）

4. 无 abbrlink、无随机哈希、不依赖数据库文件

## 六、日常写作铁律（防止以后出错）

1. **永远不要手动修改文章 front\-matter 里的 date 时间**

2. 只改正文内容 → 链接永久不变

3. 不删除 source/images（未完全迁移 R2 前）

4. 每次大批量写完文章，备份一次完整文件夹

## 七、未来 R2 图床成型后补充规则（预留）

图片全部云端存储，本地无需存图。
md 全部是外网 R2 链接，重装系统**彻底不担心图片丢失**。

## 八、终极一句话总结

**只要 blog\-hexo 文件夹在，博客永远在，无需记忆任何配置。**
