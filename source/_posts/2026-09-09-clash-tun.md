我学会了配置 Clash 虚拟网卡（TUN模式）


最近在使用 Git 推送代码时，我遇到了终端网络不通、推送超时的问题。通过学习，我成功掌握了 Clash TUN 虚拟网卡的配置方法，解决了开发中的网络难题。
普通的系统代理只能接管浏览器流量，无法作用于终端和 Git，这也是代码推送失败的主要原因。而 TUN 虚拟网卡属于系统级网络接管，开启后会自动生成一块 Meta 虚拟网卡，让所有程序、命令行、Git 流量正常转发。
我学会了完整的使用流程：开启 Clash 的 TUN 模式后，通过 PowerShell 执行 Get-NetAdapter 可以看到 Meta 网卡正常运行，ipconfig 也能看到虚拟网卡的专属 IP。此时直接使用 Git 推送、更新 Hexo 博客代码都十分稳定。
最重要的是我掌握了用完恢复网络的方法：代码推送完成后关闭 TUN，虚拟网卡自动卸载，电脑恢复原本的物理网络，无需修改任何 Git 配置，非常方便。
这次学习让我明白了系统代理与虚拟网卡的区别，不仅解决了实际开发问题，也加深了我对电脑网络路由的理解。
