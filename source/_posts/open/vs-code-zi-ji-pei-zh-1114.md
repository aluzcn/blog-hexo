你可以导出导入，**你写的快捷键 `keybindings.json`、代码片段 `markdown.json` 全都可以备份迁移**，
有两种方案：手动复制文件（最简单）、VS Code 内置云同步GitHub。

## 📁方案 1：手动备份（推荐，不用登录账号，本地保存）

Windows 资源管理器地址栏粘贴下面路径直接打开：
```
%APPDATA%\Code\User
```
这里就是全部用户配置目录。

### 需要备份的 3 样东西（就是你现在改的）

1. `keybindings.json` → 全部自定义快捷键（`Alt+I`、`Ctrl+Enter` md 专用等）
2. 整个 **`snippets`文件夹** → 里面放所有代码片段，包含你的`markdown.json`
3. `settings.json` → VS Code 各项界面设置
> 
> 备份：把这几个复制到 U 盘、硬盘。
> 恢复（新电脑 / 重装后）：关闭 VS Code，粘贴回这个目录覆盖，重启 VS Code 就全部生效。

> 
> ⚠️注意：**扩展插件不会跟着文件备份**，文件只备份快捷键、片段、设置；插件要另外记录名字重新安装。

## ☁方案 2：VS Code 官方内置「设置同步」（云同步，多台电脑自动同步）

1. 点左下角齿轮图标 → **备份和同步设置**Visual Stu...
2. 登录微软 / GitHub 账号
3. 勾选：设置、键盘快捷键、用户代码片段、扩展。开启同步。
> 
> 开启之后，你的`keybindings.json`、`markdown.json`片段、所有设置、插件列表自动上传云端。新电脑登录同一个账号，全部自动下载回来。
> 优点：全自动；缺点：需要登录账号。

### 两者对比

表格

| 方式 | 优点 | 缺点 |
| --- | --- | --- |
| 手动复制文件 | 不用登录，本地保存，简单直接 | 换电脑需要手动拷贝文件 |
| 官方云同步 | 多设备一键自动同步 | 需要登录账号 |

### 小提醒

你之前折腾的全部自定义：

- `Alt+I`图片快捷键
- `Ctrl+Enter` md 里面输出`<br>`
- `markdown.json`代码片段
全部保存在上面这几个文件，备份好，重装系统也不会丢。

> 
> 小建议：没事可以把 `User` 目录下的 `keybindings.json` 和 `snippets` 文件夹
复制一份存到桌面备份，几分钟的事，避免重装 VS Code 重新写一遍。
