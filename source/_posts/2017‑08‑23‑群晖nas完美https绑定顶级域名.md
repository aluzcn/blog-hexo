　　前天花了5800多元买了群晖的716+II，昨天下午到货。研究了一下，终于解决了顶级域名绑定到nas
实现访问的功能。尽管路由器是动态更新IP，但一点感觉也没有，就像是购买的空间一样。
　　唯一是注意是就是只能通过https方式访问，http方式不行，因为80口就封杀了，这是没有办法的。
　　Nas到手后，首先要安装web station，phpmyadmin(提示要同时安装Mariadb 10，php等等)，一齐
安装吧，包括apache 2.4/2.2 Php  5.6/7.0等。如果在线安装太慢，你可以从群晖的网站下载到本地再手
动安装就快很多很多的。https://www.synology.cn/zh-cn/support/download/DS716+II#packages

　　记得以前的qnap是可以下载wordpress到主目录或者子目录下，再通过网页的方式安装的。但在群晖
上试了几次都不行，web station中的http后台服务器用Nginx，安装时提示405错误，用apache 2.4或者2.2
又提示连接不上数据库。最后没有办法只能下载群晖的wordpress套件来安装，非常顺利，但只能安装在
web/wordpress目录下，数据库可以选择wordpress外的其他名字，自动建立这个数据库。

　　后来想到总是通过https://....../wordpress来访问，多个尾巴太讨厌。想起了虚拟主机这个功能。结果
彻底解决。

  注意：在我的Nas上最下面的两个必须是 apache http server 2.4和 php5.6，试了其他的都不行。
  https://aluz.cn下就是好，根本不需要在路由器中再设置比如88到80的映射等了，放弃http方式吧。
路由器上的设置也是自动通过Upnp自动解决的。很好。 

　　别忘记到wordpress中修改一下域名，再用sql语法将http://mson.top这个老域名转换成
https://aluz.cn这个新域名，转换时要输入http和https，因为访问方式也不同了。

　　另外wordpress安装结束用https访问时，打开具体文章的链接会提示错误，将群晖自动生成的
.htaccess用我原来Nas的同名文件替换就OK了。、见 https://aluz.cn/nas/2286.html
